# Mane Explora

Blog estático de reseñas honestas. Se genera con `python3 build.py` (requiere `markdown` y `pyyaml`) y publica `dist/`.

- Nueva reseña: agregar `content/resenas/<slug>.md` + fotos en `static/img/<lugar>/`.
- AdSense: llenar `adsense_client` en `build.py` cuando Google apruebe el sitio.
